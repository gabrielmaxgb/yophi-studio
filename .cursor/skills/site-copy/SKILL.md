# Site copy — YOPHI

Load this before touching `src/lib/dictionary.ts` or any user-facing string.

YOPHI (יֹפִי, Hebrew: beauty) is a studio for presence: strategy, content, design, technology. Not a formula shop. Not a vitrine.

## Voice

Sound like a sharp person who already did the work — explaining it, not selling it.

- PT-BR first. Spoken Brasília/SP professional, not advertising-agency Portuguese.
- "A gente" is the studio. Not "nós somos uma equipe apaixonada".
- Short sentences. Periods. Em dash when it earns it.
- Name the thing: the domain, the city, the craft. No "solução completa".
- One idea per line. If it can lose a clause, lose it.

Brand nouns (use sparingly, they already carry the thesis): presença, conjunto, arquivo.

Never use "com opinião" / "with a point of view" as a slogan. Too vague. Say what shows up.

## Do

- Problem → what was wrong **online**. Solution → what we put **in the air**.
- Case study: two beats. First the before. Then the site, named.
- CTAs: verb + object. "Começar um projeto". "Abrir o site".
- Meta: same claim as the page, shorter. No keyword stuffing.

## Don't

English parked in PT-BR: hero, pitch, delivery, mindset, insights, storytelling, premium (as decoration).

Hollow marketing: jornada, ecossistema, neste sentido, sem fórmula, sem costura, elevar a marca, desbloquear, transformar.

Stacked slogans. Three true sentences beat one clever one.

Chat: bora, curto, cara, mano — unless the user wrote it.

Don't flatten a line that's already sharp. maxdecoyer is the bar:

> O trabalho já existia. Online, sumia no meio de todo mundo com o mesmo site de fotógrafo.

## Case studies

```
sector: one word (Fotografia, Odontologia)
disciplines: 2–3 crafts we actually did
problem: what failed on the internet (not the client's life story)
solution: the site, named, and what it does instead
outcomes: 3 short facts (Site, PT / EN, Brasília)
```

The cover title is the client name. Copy should not repeat the biography.

## Pass

1. Read the existing PT line. Keep the meaning if it's already good.
2. Cut English calques and empty slogans.
3. Read it out loud. If you wouldn't say it in a meeting, rewrite.
4. EN only if asked — and then same meaning, not a new ad.

If it sounds like Generic Studio or like a LinkedIn post, rewrite once: specific, short, named.
