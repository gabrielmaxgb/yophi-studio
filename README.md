# YOPHI Studio

Premium creative studio site — Next.js, Tailwind, shadcn/ui, Anime.js.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router
- Tailwind CSS v4 + shadcn/ui
- Anime.js for motion
- Instrument Serif + DM Sans
